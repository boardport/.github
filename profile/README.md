### $ cat /etc/boardport/mission.txt

**BoardPort** is an open research ecosystem dedicated to giving hardware a "second life".

Millions of low-cost 4G USB modems, compact Wi-Fi routers (dongles), legacy smartphones, and development boards are powered
by capable 64-bit multi-core Qualcomm Snapdragon processors (MSM8916, MSM8909, MSM8937).
However, factory vendor shipments lock them into obsolete firmware running outdated Android versions and legacy 3.10 kernels.

**Our Mission:**

- Provide reliable, containerized tooling for low-level recovery and partition extraction (EDL 9008).
- Adapt open secondary bootloaders (`lk2nd`, `U-Boot`) and Device Trees.
- Enable booting modern mainline Linux kernels and lightweight distributions (Debian, Alpine, OpenWrt, postmarketOS).

We transform potential "electronic waste" into fully functional standalone micro-servers, network gateways, routers, and automation nodes.
